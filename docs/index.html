Rule sensitivity in detail

What each defensible reading actually scores, dimension by dimension. The largest single swing in the whole report comes from the character rule, where counting only non-whitespace characters takes the reference answers from full marks to nothing, because every one of them was composed to hit a code point target with the spaces included. That is the honest shape of the problem. A character constraint is close to meaningless without a stated definition, and a benchmark that picks one silently is publishing its own choice as a property of the models.
